# Development

## Setup

```bash
pnpm install
```

## Build

```bash
pnpm build
```

## Test

```bash
pnpm test
```

## Lint

```bash
pnpm lint
```

## Format

```bash
pnpm format
```

To check formatting without writing files:

```bash
pnpm format:check
```

## Type Check

```bash
pnpm type-check
```
